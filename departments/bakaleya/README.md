### Ежедневный снимок

```bash
python departments/bakaleya/refetch.py departments/bakaleya/data/snapshot-metro-cc-2026-08-29T13-50.json
python -m core.build --data departments/bakaleya/data
```

`refetch.py` перезапрашивает те же URL и пишет новый снимок с текущим временем:
страница не открылась → `unknown`, весь источник не открылся → `unreachable`,
наличие — только по микроразметке. Стандартная библиотека, без ключей.
