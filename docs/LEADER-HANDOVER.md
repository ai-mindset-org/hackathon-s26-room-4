## Что делает лидер

1. **Мержит PR.** Ревью: тесты модуля (`python -m pytest <папка>/ -q`),
   данные отделов — `python -m core.build --data departments/<отдел>/data`.
   Docs и данные в своей папке — мержить смело; правки чужих модулей — только
   со словом автора модуля.
2. **Пересобирает и деплоит дашборд после каждого мержа:**
   ```bash
   python -m core.kitchen
   netlify deploy --prod --dir site
   ```
3. Держит `main` зелёным: приёмка — `examples/`, команды в `core/README.md`.

## Доступы

- **Мерж:** права выдаёт проводник (написать в зум-чат свой GitHub-логин).
- **Netlify‑сайт `room4-kitchen`** висит на аккаунте Михаила. Если деплоить
  некому: `site/` закоммичен в main — поднять свой сайт = `netlify deploy
  --prod --dir site` под любым аккаунтом (новый URL сказать комнате), либо
  показывать `site/index.html` локально из клона.
- Секретов в репо нет, ничего приватного для передачи не требуется.
