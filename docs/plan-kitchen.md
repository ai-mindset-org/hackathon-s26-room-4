## Правила отдела

1. Папка отдела — твоя целиком: источники, код, дизайн странички — на твой вкус.
2. **Снимки цен — в `departments/<отдел>/data/*.json` в контракте v2** (см. ниже).
   Это единственное жёсткое требование: по нему дашборд собирает твой отдел.
3. Страничка отдела (если делаешь) — `departments/<отдел>/index.html`,
   дашборд сам подхватит и слинкует.
4. Стартовый промпт для агента лежит в `departments/<отдел>/README.md` —
   нулевая точка, дальше веди как хочешь.

## Контракт снимка v2 (issue #4, реализован в core/)

```json
{"taken_at": "2026-08-29T12:00:00", "source": "домен-источника",
 "source_status": "ok|unreachable",
 "items": {"sku-или-артикул": {"shop": "магазин", "title": "название",
   "price": 129.0, "currency": "RUB",
   "price_status": "listed|on_request|unknown", "in_stock": true}}}
```

Честность: источник не ответил → `source_status: unreachable` (это НЕ «пропало»);
цена-заглушка / «по запросу» → `price_status: on_request`.
Пороги заказчика: рост ≥10% — красный флаг, ≥5% — жёлтый.

## Проверка своего отдела локально

```bash
python -m core.build --data departments/<отдел>/data          # дайджест отдела
python -m core.kitchen                                         # пересобрать дашборд
```

## Письменное ТЗ заказчика K4UR — как закрываем (по радару)

Из `docs/interview-K4UR.md`: формат — **Excel**, готов к **10:00**, канал —
почта; поля: наименование, цена пред./тек. закупки, параметры, поставщик,
контакты, MOQ, форма оплаты; изменения <5% — шум.

- **Excel**: `site/kitchen-digest.xlsx`, кнопка «Excel для закупки ⤓» на
  дашборде; красный/жёлтый/зелёный — заливкой строк. Контакты поставщика —
  поле `shop` снимка (пример: fishnet, «Уайк, ООО · +7(929)504-88-90»),
  параметры — в `title`. MOQ/оплата: колонки зарезервированы, источники их
  пока не отдают — честно помечено в файле.
- **К 10:00 по почте**: после хакатона — cron `python -m core.kitchen` +
  отправка файла письмом; на демо показываем ручной запуск.
- Веб-страничка — решение комнаты для общей видимости, Excel — канал
  заказчика; одно другому не противоречит: оба собираются из одних пар.

## Два diff-движка — зафиксировано

В main работает `core/fallback_diff.py`; `diff/` Кирилла смержен как
отдельный модуль. Дублирование признано: после демо интерфейс
`diff.engine.diff_snapshots(a,b)` — и core переключается автоматически
(см. комментарий в PR #24). До демо движок не меняем.
