# Комната 4 · Мониторинг → дайджест

Хакатон AI Mindset S26 «Чужая боль» · 29.08.2026 · 10:00–14:00 CET

## 🍽 Живой дашборд: https://room4-kitchen.netlify.app

Концепция «Кухня ресторана» — план в `docs/plan-kitchen.md`. Каждый ведёт свой
отдел: стартовый промпт для агента — `departments/<твой-отдел>/README.md`
(скопируй агенту целиком), снимки цен — в `departments/<твой-отдел>/data/`.
На карточке отдела — образец дайджеста, каким он станет с твоими данными.
После мержа лидер пересобирает (`python -m core.kitchen`) и передеплоивает.

## Задача

Регулярное слежение руками: цены конкурентов и поставщиков, тренды, твиттер,
показатели. Каждый день одни и те же открывания страниц и сравнивания цифр.

**Строим:** инструмент, который по списку источников собирает свежие значения,
сравнивает с прошлым снимком и отдаёт дайджест изменений: что сдвинулось,
на сколько, в какую сторону, с историей для графика. Снимки лежат в репо —
динамика видна без базы данных.

Опорный пример от заказчика: цены на конкретные диски по парт-номерам в пяти
онлайн-магазинах, динамика в процентах за день. Рядом: исследования конкурентов и трендов; метрики выручки; учёт, куда
уходит время и внимание, по логам агентских сессий; подборка теории
к собеседованию под профиль компании.

## Приёмка одним запуском

```bash
python3 check.py
```

Гоняет все `examples/` через инструмент и печатает «прошло N из M».
Только стандартная библиотека, pytest не требуется.

## Как работаем с кодом

- **Fork → ветка → PR.** Агент делает это сам: `gh repo fork ai-mindset-org/hackathon-s26-room-4 --clone`,
  ветка `КОД-УЧАСТНИКА/что-делаю`, `gh pr create --fill`. Мержит лидер комнаты.
- **Один участник — один модуль или папка.** Кто что берёт — решаем в комнате,
  фиксируем issues. Так PR не дерутся между собой.
- Конфликт: `git remote add upstream https://github.com/ai-mindset-org/hackathon-s26-room-4` →
  `git pull --rebase upstream main`.
- Интервью с заказчиками кладём в `docs/interview-КОД.md`.
- **Секретов в репозитории не бывает.** Репо публичный. `.env` в `.gitignore`,
  ключи живут только на вашей машине.
- После каждого мержа гоняем `examples/` — они и есть приёмка.

## Приёмка

В `examples/` лежат входы с ожидаемым результатом (собраны из болей заказчиков). Итог демо: «прошло N из M» + вердикт заказчиков
«решило / не решило». Частичный результат — тоже результат.
